～テーブルの検索（SELECT）～
≪ SELECT文の構造≫
SELECT ID , NAME ,GENDER , BIRTHDAY , WEIGHT
FROM SAMPLE_4_1

FROM句:どのテーブルから
SELECT句:どのカラムのデータを抽出するか
SELECTによるデータ抽出は「クエリ」「問い合わせ」と
呼ばれることがあります。


### SELECT文の構造
SELECT ID , NAME ,GENDER , BIRTHDAY , WEIGHT
  FROM SAMPLE_4_1 ;

### 全カラム抽出「 * 」
SELECT *
  FROM SAMPLE_4_1 ;

### 別名の付与（AS）
SELECT ID       AS PET_ID       , 
       NAME     AS PET_NAME     ,
       GENDER   AS PET_GENDER   ,
       BIRTHDAY AS PET_BIRTHDAY ,
       WEIGHT   AS PET_WEIGHT
  FROM SAMPLE_4_1 ;
