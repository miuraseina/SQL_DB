～さまざまなデータ型（文字型）～
nはバイト数ではなく文字数！
半角全角などによるバイト数の考慮は不要です！
文字列の型の指定では、
文字列の長さを強く意識する
CHAR:固定文字数型、文字数に達しない場合半角スペースで埋める
VARCHAR:可変文字数、文字数に達しない場合でも半角スペースで埋めない
CREATE TABLE SAMPLE_3_4_2 ( x1 CHAR(5) , x2 VARCHAR(5) );
INSERT INTO  SAMPLE_3_4_2 ( x1 , x2 ) VALUES ('abcde' , 'abcde');
INSERT INTO  SAMPLE_3_4_2 ( x1 , x2 ) VALUES ('abc' , 'abc');
