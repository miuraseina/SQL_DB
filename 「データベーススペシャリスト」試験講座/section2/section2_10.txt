商品テーブルから、商品名が「ボールペン」から始まる⾏を取得する
SELECT * FROM 商品 WHERE 商品名 LIKE ’ボールペン%’
※NULLは「不明」「存在しない」なので、普通の⼿段では⽐較できない％は任意の文字を意味する
商品テーブルから、商品名が「ラーメン」で終わる⾏を取得する
SELECT * FROM 商品 WHERE 商品名 LIKE ’%ラーメン’
商品テーブルから、商品名が「ボールペン」から始まらない⾏を取得する
SELECT * FROM 商品 WHERE 商品名NOTLIKE’ボールペン%’

※'先頭文字%'

商品テーブルから商品名が「ボールペン」から始まり
かつ単価が１３０円以下の⾏を取得する
SELECT * FROM 商品
WHERE商品名LIKE ’ボールペン%’AND単価<= 130
商品テーブルから商品名が
「ボールペン」または「鉛筆」または「消しゴム」の⾏を取得する
SELECT * FROM 商品WHERE
商品名= ’ボールペン’OR 商品名= ’鉛筆’OR 商品名= ’消しゴム’

３００円以上の鉛筆または、ボールペンを取得する
SELECT * FROM 商品 WHERE 
単価>= 300 AND商品名= ’鉛筆’OR 商品名= ’ボールペン’
計算と同じく、掛け算（積、AND）が優先
３００円以上の、鉛筆またはボールペンを取得する
SELECT * FROM 商品
WHERE
単価>= 300 AND( 商品名= ’鉛筆’ OR 商品名= ’ボールペン’ )
かっこが最優先
