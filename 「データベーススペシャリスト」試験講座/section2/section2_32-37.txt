副問合せをした結果を使って外側のSQLを実⾏する
//INの場合、内側（副問合せ）の結果が複数⾏であってもよい
SELECT 商品名

SELECT 商品コード

外側のテーブルから値を内側に渡して実⾏し、
結果が存在していればその⾏を表⽰
SELECT 商品名
FROM 商品
WHERE EXISTS (
SELECT * 
FROM 売上明細
WHERE 商品コード= 商品.商品コード
)
ただの副問合せとの違いに注意
