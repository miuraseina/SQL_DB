SELECT項⽬名,項⽬名,項⽬名・・・
FROM テーブル名
ORDER BY 項⽬名, 項⽬名, 項⽬名,・・・
結果を並び替えます
並び替えの基準となる項⽬は複数指定
できます
昇順と降順の指定が可能です

商品コードの順に並び替える
SELECT *
FROM 商品
ORDER BY商品コード

グルーピングや集約関数を使った結果に対しての並び替え
SELECT 商品コード, SUM(数量)
FROM 売上明細
GROUP BY 商品コード
HAVING SUM(数量)> 20
ORDER BY SUM(数量)

商品コードの降順に並び替える
SELECT *
FROM 商品
ORDER BY 商品コードDESC

グルーピングや集計関数を使った結果に対しての並び替え
SELECT 商品コード, SUM(数量)
FROM 売上明細
GROUP BY 商品コード
HAVING SUM(数量) > 20
ORDER BY 2
