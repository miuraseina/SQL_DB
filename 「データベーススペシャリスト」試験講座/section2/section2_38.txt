追加
INSERT INTO テーブル名(項⽬名・・・)
VALUES (定数・・・)
※またはSELECTでの選択
定数を列挙して記述する⽅法と
SQL⽂で選択をする⽅法とがあります
項⽬名の列挙を省略すると、⾃動で
全ての項⽬となります

会員テーブルにデータを⼀件追加する
INSERT INTO 会員(会員コード, ⽒名, ポイント, 最終使⽤⽇)
VALUES (101, ʼ⽯⽥宏実ʼ, 123, ʼ2024-10-11ʼ)
項⽬名の列挙を省略すると
⾃動ですべての項⽬が
定義順に記述される
INSERT INTO 会員(会員コード, ⽒名, ポイント)
VALUES (101, ʼ⽯⽥宏実ʼ, 123)
未指定の項⽬には
デフォルト値が⾃動的に⼊る

会員テーブルにSQL⽂で選択したデータを追加する
INSERT INTO 会員(会員コード, ⽒名, ポイント, 最終使⽤
⽇)
SELECT 102, ⽒名, ポイント, 最終使⽤⽇
FROM 会員
WHERE 会員コード= 1 

以下のテーブルがある。
　・テーブル名：member
　・項目：
　　　memberCode
　　　name
　　　point
　　　lastUsedDate
このテーブルに以下の１行を追加する
memberCodeに「1」
nameに「札幌一郎」
pointに「100」
lastUsedDateに「2023-12-31」
なお上記の数値は全て半角とし、名前は全角とする。
その後、memberテーブルの行をすべて表示する。

更新
UPDATE テーブル名
SET 項⽬名= 値, ・・・・
WHERE 条件式
更新したい項⽬名だけを列挙します
条件を指定しないとすべてが更新されます

会員テーブルのある⼀件の⽒名と最終使⽤⽇を更新する
UPDATE会員
SET⽒名= ʼ⼭⽥太郎ʼ, 最終使⽤⽇= ʼ2024-10-20ʼ
WHERE 会員コード= 101

削除
DELETE 
FROM テーブル名
WHERE 条件式
⾏ごと削除するので項⽬名は不要です
条件を指定しないとすべてが削除されます

会員テーブルのある⼀件を削除する
DELETE FROM 会員
WHERE 会員コード= 101
