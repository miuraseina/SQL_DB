トランザクション管理
⼀連の複数処理をまとめたもの
コミット
⼀連の処理をすべて確定すること
ロールバック
処理をキャンセルしてトランザクション開始前の状態に戻すこと

トランザクション管理
会員テーブルの⽒名の更新をコミットして確定させる
START TRANSACTION   //トランザクションの開始//トランザクション開始はBEGINでもよい（MySQLの場合）
UPDATE 会員 SET ⽒名= ʼ⽯⽥ʼ 
WHERE 会員コード= 101
COMMIT              //コミットしてからトランザクションを終了

会員テーブルの⽒名の更新をロールバックしてキャンセルする
BEGIN   //トランザクションの開始
UPDATE 会員 SET ⽒名= ʼ⽯⽥ʼ 
WHERE 会員コード= 101
ROLLBACK
ロールバックしてからトランザクションを終了
